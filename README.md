# Справочник сотрудников ПАО «СН-МНГ» — Управление TrueConf

Веб-приложение для управления справочником сотрудников с автоматическим сопоставлением данных TrueConf.

## 🚀 Быстрый старт

### Вариант 1: Использовать готовую сборку (рекомендуется)

Приложение уже собрано и доступно через превью. Просто откройте его и пользуйтесь.

### Вариант 2: Запустить локально

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Открыть http://localhost:3000
```

### Вариант 3: Собрать production-версию

```bash
npm run build

# Готовые файлы в папке dist/
# Откройте dist/index.html в браузере
```

## 🛡 Режимы доступа

- **Просмотрщик (гость)** — поиск, фильтрация, звонки в TrueConf; ячейки ФИО/должности/ID защищены от правки.
- **Администратор** (кнопка «🔐 Администратор» в шапке, пароль задаётся при первом входе) — полное редактирование всех основных полей, добавление/удаление строк, автозаполнение ФИО из выгрузок TrueConf_User и экспорт с живыми формулами HYPERLINK.

## 📦 Как пользоваться

1. **Загрузите справочник** (.xlsx) — основной файл с сотрудниками
2. **Загрузите файлы TrueConf** — можно несколько файлов одновременно
3. **Нажмите «🚀 Запустить сопоставление»** — система автоматически сопоставит данные
4. **Редактируйте данные** — кликните по ячейке для редактирования
5. **Экспортируйте результат** — нажмите «📥 Excel» для скачивания

## 💾 Контейнер данных

Все данные хранятся в изолированном контейнере (IndexedDB браузера):

- ✅ **Автосохранение** — каждые 800мс
- ✅ **Изоляция** — данные не покидают приложение
- ✅ **История** — все действия записываются
- ✅ **Экспорт/импорт проекта** — файл `.spravochnik`

### Кнопки управления:

- **📦 Контейнер** — панель управления данными (в шапке)
- **💾** — сохранить проект в файл
- **📂** — загрузить проект из файла
- **📥 Excel** — экспортировать справочник

## 📋 Форматы файлов

### Справочник сотрудников (10 колонок):

1. Фамилия Имя Отчество
2. Должность
3. № Кабинета
4. № Телефона
5. № Корпоративный мобильный телефон
6. Тип телефонной линии
7. Звонок в TrueConf
8. Звонок на № телефона с TrueConf
9. ID TrueConf
10. #телефона

### Файлы TrueConf (9 колонок):

1. Логин
2. ФИО
3. Регион
4. Сервер
5. Атрибут (ID TrueConf)
6. Компания
7. Email
8. Дата предоставления доступа
9. Дата первого входа

## 🔄 Логика сопоставления

1. **Точное совпадение** — ФИО + Компания (целевые: МЭН, ПАО СН-МНГ, МУБР)
2. **Поиск по ФИО** — если не найдено точное совпадение
3. **Нормализация** — нижний регистр, удаление двойных пробелов, замена «ё» → «е»

## 🔗 Генерация гиперссылок

- **Звонок в TrueConf:** `trueconf:{ID}?do=profile`
- **Звонок на телефон:** `Trueconf:#tel:{номер}`
