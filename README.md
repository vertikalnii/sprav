# Справочник сотрудников ПАО «СН-МНГ» — Управление TrueConf

Веб-приложение для управления справочником сотрудников с автоматическим сопоставлением данных TrueConf.

## 📦 Готовое решение БЕЗ Docker и без установки (рекомендуется)

Всё приложение собирается в **один HTML-файл** со встроенными JS/CSS — запускается двойным щелчком на Windows и Linux, работает офлайн, устанавливать ничего не нужно:

```bash
npx vite build --config vite.config.single.js   # результат: dist-single/index.html
```

Готовый архив: `release/spravochnik-web.zip` (СПРАВОЧНИК-СН-МНГ.html + Запуск-Windows.bat + Запуск-Linux.sh + README-ЗАПУСК.md).
Подробная инструкция — в файле `README-ЗАПУСК.md`.

## 🚀 Быстрый старт — решение в контейнере (Docker, опционально)

Все установки (Node.js, зависимости, сборка) выполняются **внутри Docker-контейнера**.
На вашем компьютере не нужно ничего устанавливать, кроме Docker. Одинаково на Windows и Linux.

**Windows:** дважды щёлкните `run-windows.bat` (или в папке проекта выполните `docker compose up -d --build`).

**Linux:**

```bash
chmod +x run-linux.sh && ./run-linux.sh   # или: docker compose up -d --build
```

После сборки откройте в браузере: **http://localhost:8080**
Для сотрудников сети: **http://ИМЯ-ИЛИ-IP-СЕРВЕРА:8080**

Полезные команды:

```bash
docker compose logs -f        # журнал сервера
docker compose restart        # перезапуск
docker compose down           # остановка
docker save spravochnik-sn-mng:latest -o spravochnik.tar   # перенос образа на офлайн-машину
docker load -i spravochnik.tar                             # ...и загрузка там
```

Файлы решения: `Dockerfile` (multi-stage: node:20-alpine → nginx:1.27-alpine),
`docker-compose.yml`, `deploy/nginx.conf`, `.dockerignore`, `run-windows.bat`, `run-linux.sh`.

### Альтернатива без Docker

```bash
npm install && npm run build   # готовые файлы в dist/, откройте dist/index.html
```

## 🌐 Публикация на общем сетевом ресурсе

Сборка в `dist/` использует относительные пути (`base: './'`), поэтому её можно опубликовать двумя способами:

**Способ 1 — просто скопировать папку `dist/` на сетевой ресурс (UNC):**

```
\\server\share\spravochnik\   ← содержимое dist/ (index.html + assets/)
```

Каждый сотрудник открывает `\\server\share\spravochnik\index.html` двойным щелчком или через браузер (`file://`). Работает на Windows и Linux — достаточно любого браузера: Chrome, Firefox, Edge, Яндекс.Браузер). Данные при этом хранятся локально в IndexedDB каждого браузера; для переноса между машинами используйте «💾 Сохранить проект» → файл `.spravochnik`.

**Способ 2 — лёгкий HTTP-сервер на хосте сети (рекомендуется для единой точки данных):**

Windows (в папке `dist\`):
```powershell
python -m http.server 8080
```

Linux (systemd-юнит для автозапуска):
```bash
python3 -m http.server 8080 --directory /srv/spravochnik/dist
# или: sudo systemctl enable --now spravochnik.service
```

Сотрудники открывают `http://имя-хоста:8080/`. Ссылки звонков `trueconf:` и `Trueconf:#tel:` работают из любого браузера при установленном клиенте TrueConf на машине пользователя.

## 🛡 Режимы доступа

- **Просмотрщик (гость)** — поиск, фильтрация, звонки в TrueConf; ячейки ФИО/должности/ID защищены от правки.
- **Администратор** (кнопка «🔐 Администратор» в шапке, пароль задаётся при первом входе) — полное редактирование всех основных полей, добавление/удаление строк, автозаполнение ФИО из выгрузок TrueConf_User и экспорт с живыми формулами HYPERLINK.

## 📦 Как пользоваться

1. **Загрузите справочник** (.xlsx) — основной файл с сотрудниками
2. **Загрузите файлы TrueConf** — можно несколько файлов одновременно

5. **Экспортируйте результат** — нажмите «📥 Excel» для скачивания

## 🔄 Логика сопоставления

1. **Точное совпадение** — ФИО + Компания (целевые: МЭН, ПАО СН-МНГ, МУБР)
2. **Поиск по ФИО** — если не найдено точное совпадение
3. **Нормализация** — нижний регистр, удаление двойных пробелов, замена «ё» → «е»

## 🔗 Генерация гиперссылок

- **Звонок в TrueConf:** `trueconf:{ID}?do=profile`
- **Звонок на телефон:** `Trueconf:#tel:{номер}`

## 🧩 Макрос Excel (Module1_.bas)

`.bas`-файл хранится **в кодировке Windows-1251**, т.к. редактор VBA импортирует модули как ANSI-текст (CP1251). Поэтому предпросмотр `Module1_.bas` на GitHub может показывать русские буквы некорректно — это норма для этого файла. Не перекодируйте его в UTF-8: иначе после импорта в VBA русский текст в коде превратится в «РіРёРї…», и логика макроса (заголовки разделов, подписи гиперссылок) сломается.

Импорт: **Alt+F11 → File → Import File… → Module1_.bas**

Возможности макроса:
- ID TrueConf из выгрузок (`TrueConf User_*.xlsx`) заполняется в колонку I по ФИО (+ класс компании);
- формулы гиперссылок записываются в **каждую** строку справочника: колонка G (`Вызов по TrueConf`, по ID) и колонка H (`Позвонить на № телефона`, по J) — ссылка в H появляется, как только вручную заполнена колонка J «#телефона» (она переводится в текстовый формат, чтобы `051…` не терял ведущий ноль);
- компания приводится к классу **МЭН / ПАО / МУБР** (файлы содержат `OOO "МЭН"`, `ПАО «СН-МНГ»`, `OOO "МУБР"`); при пустой колонке M класс определяется по ближайшему заголовку раздела;
- отчёты «Расхождения» и «Отчет_по_категориям» создаются заново при каждом запуске (скрытые листы; показать — макросы ToggleDiscrepancySheet / ToggleCategoryReport).
