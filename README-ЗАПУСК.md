# СПРАВОЧНИК СН-МНГ — запуск БЕЗ Docker и без установки программ

Готовое решение распространяется одним архивом `release/spravochnik-web.zip`.
Внутри — **один HTML-файл** со всей программой (JS/CSS встроены) и скрипты запуска.

## Состав архива
| Файл | Назначение |
|---|---|
| `СПРАВОЧНИК-СН-МНГ.html` | Всё приложение в одном файле: справочник, автозаполнение ФИО из выгрузок TrueConf_User (3 компании), режим Администратора, звонки в TrueConf по ID и по номеру, экспорт Excel с формулами HYPERLINK |
| `Запуск-Windows.bat` | Двойной клик — открывает приложение в Edge/Chrome как отдельное окно программы |
| `Запуск-Linux.sh`   | `./Запуск-Linux.sh` — локальный HTTP-сервер на Python 3 (есть во всех дистрибутивах) или просто откройте HTML в браузере |

## Вариант 1 — самый простой (Windows и Linux)
1. Распакуйте архив в любую папку (можно на общий сетевой ресурс `\\сервер\share\spravochnik`).
2. Дважды щёлкните `СПРАВОЧНИК-СН-МНГ.html` — он откроется в браузере. Всё работает офлайн, ничего устанавливать не нужно.

## Вариант 2 — сервер на общем ресурсе (сотрудники по сети)
На машине-хосте:
- Windows: двойной клик `Запуск-Windows.bat` (или `python -m http.server 8080 --directory dist`);
- Linux: `./launch-linux.sh 8080`.

Сотрудники открывают в браузере: `http://ИМЯ-ХОСТА:8080`.

## Данные
- Справочник, выгрузки и история хранятся в браузере каждой машины (IndexedDB).
- Для переноса/резервной копии используйте «Экспорт проекта» (.spravochnik) и «Импорт проекта».
- Первый вход в режим Администратора: «🔐 Администратор» → задайте пароль.

## Звонки в TrueConf
Работают ссылки `trueconf://ID?do=profile` и `Trueconf:#tel:номер` — на компьютере должен быть установлен клиент TrueConf (это требование TrueConf, а не нашего решения).

## Обновление решения
После изменений в исходниках пересоберите один файл:
```bash
npm ci && npx vite build --config vite.config.single.js
```
и замените `СПРАВОЧНИК-СН-МНГ.html` в сетевой папке.
